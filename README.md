# Unity

Biblioteca de **módulos reutilizáveis em PHP puro**, sem framework.

É a irmã do [Lore](https://github.com/darlisamorim/Lore): o Lore reúne módulos para
projetos **Laravel**, e o Unity reúne módulos para projetos **PHP puro**, como os criados a
partir do template [Cerberus](https://github.com/darlisamorim/Cerberus).

## Módulos

| Módulo | O que faz | Situação |
|---|---|---|
| **E-mail** | Formulário → template HTML → envio por SMTP com PHPMailer | Primeira versão feita, vai ser refeita |
| *(outros)* | A definir | — |

**Base usada até aqui:** `phpmailer/phpmailer`, `vlucas/phpdotenv` (configuração pelo
`.env`) e `coffeecode/router` (rotas).
